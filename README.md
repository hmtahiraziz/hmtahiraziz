- Supports **chat history** for contextual follow-up questions

#### **FAQ Hybrid Search Chatbot (FastAPI + Pinecone + Ollama)**
Developed a **FAQ-based chatbot** that answers company or app-related queries using **hybrid search** — combining **dense and sparse vector retrieval**.  
It loads FAQs from JSON, encodes them with **BM25 + MiniLM**, and stores them in **Pinecone** for semantic and keyword matching.  
- Incorporates **CrossEncoder reranking** for accuracy  
- Maintains short **conversation history** for contextual responses  
- Powered by **FastAPI**, **LangChain**, and **ChatOllama (Mistral)**
